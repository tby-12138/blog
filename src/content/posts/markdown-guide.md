这篇文章既是排版示例，也是一份速查表。在管理台里写 Markdown 时，可以随时回来看看效果。

## 标题与段落

用 `##` 到 `####` 表示不同层级的标题。二级和三级标题会自动出现在右侧目录里，方便长文跳转。

段落之间空一行即可。中文排版不需要手动缩进，也不建议在段内强行换行——让浏览器自己决定折行位置。

## 强调与链接

- **加粗**用两个星号：`**加粗**`
- *斜体*用一个星号：`*斜体*`
- `行内代码`用反引号包起来
- 链接写成 `[文字](https://example.com)`
- 删除线：~~像这样~~

## 列表

无序列表适合并列的要点：

- 第一件事
- 第二件事
  - 可以嵌套
  - 但不要嵌套太深
- 第三件事

有序列表适合步骤：

1. 先写标题
2. 再写摘要
3. 最后保存并等待自动部署

## 引用

> 好的文字不是写出来的，是改出来的。
>
> 这句话提醒我：初稿允许糟糕，但发布前至少要再读一遍。

## 表格

| 元素 | 写法 | 用途 |
| --- | --- | --- |
| 标题 | `## 标题` | 划分章节 |
| 引用 | `> 文字` | 强调观点 |
| 代码 | 三个反引号 | 展示代码 |
| 图片 | `![描述](/images/a.png)` | 插入配图 |

表格在手机上会自动横向滚动，不会撑破页面。

## 代码块

代码块会带上语法高亮和复制按钮：

```js
function greet(name) {
  return `你好，${name}！`;
}

console.log(greet('世界'));
```

也支持没有语言标记的纯文本：

```text
这是一段纯文本。
不会高亮，但会保留空格和换行。
```

## 图片

在管理台点击工具栏里的图片按钮，上传后会得到类似这样的地址：

```markdown
![一张配图](/images/example.png)
```

站内绝对路径会自动适配 GitHub Pages 的子路径，所以从 `/images/` 写起就可以。
