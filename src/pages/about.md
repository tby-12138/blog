你好，我是**白雲**。

这里是我的个人博客，用来存放那些值得被写下来、也值得被重新读到的内容：技术笔记、读书摘记、偶尔的生活碎片。

## 为什么写博客

信息流擅长让人快速划过，却不太适合慢慢想清楚一件事。写下来的过程会逼着自己把模糊的直觉整理成可以检验的句子，而公开的文字又会带来一点温和的约束——既然有人可能会读，就尽量写得准确、诚实一些。

所以这个站点没有评论区，也没有推荐算法。你可以按时间读，也可以顺着标签读，或者直接订阅 RSS。

## 关于这个站点

- 使用 [Astro](https://astro.build/) 构建，输出纯静态页面。
- 部署在 GitHub Pages 上，每次提交都会自动构建。
- 文章是仓库里的 Markdown 文件，站点内置了一个浏览器管理台，可以在线新增、修改和删除文章。
- 没有后端、没有数据库，也没有第三方统计脚本。

## 联系

如果你想聊聊某篇文章，欢迎通过 GitHub 找到我。这个页面和站点里的大部分文字一样，都可以随时修改。

> 把零散的思考，写成可以重读的东西。
